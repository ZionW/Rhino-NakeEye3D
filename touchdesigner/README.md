# TouchDesigner 裸視3D 測試版

直接開啟 `CyberApple.toe`；浮動控制面板會自動顯示。點「開始 / 繼續」即可啟動 webcam。
點「暫停」保持視角並保留預覽；點「停止並恢復」釋放相機並還原開始時的視角和蘋果部件。
「目前視角校正」會以目前的頭部位置和攝影機作為新基準。

- 空間模式：頭部左右、上下、遠近控制視角；右手 / 左手揮動各轉90度，方向相反。
- 物體模式：三指抓握移動手掌以環繞攝影機；雙手只伸食指控制爆炸圖，最多分離三倍，攝影機自動容納部件。
- Webcam 預覽224×168，笑面男GIF遮罩，三指抓握紅球變綠球。找不到臉部時隱藏背景影像，保留手部提示。
- 同一時間只用一套追蹤，切換軟體前先按「停止並恢復」。

TD 使用原生 Script SOP、Camera COMP、Render TOP、Script TOP 與浮動控制面板。本機 MediaPipe 追蹤程序由面板透過已授權的相機 helper 啟動，無須終端機。
專案依賴此電腦的 `/Users/zionw/Desktop/Codex/裸視3D` 內 `.venv`、追蹤模型及 helper，不能只拷貝 tox 到別的電腦就使用 webcam。
UDP39559、記憶體預覽HTTP39560。影像不存檔或上傳。

已真人驗證 webcam 取得影像、頭部控制、暫停、恢復，以及原生遮罩預覽。三指抓握和爆炸圖控制通過資料包測試，手勢辨識仍需依個人姿勢測試。

`CyberApple.tox` 可匯入其他 TD 工程。若浮動面板關閉，到 `/project1/cyber_apple/control_panel` 右鍵 View 開啟。
重建：先執行 `build_cyber_apple.py`；此腳本包含追蹤接入與面板建置。
